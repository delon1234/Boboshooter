# Boboshooter

Boboshooter is a fast-paced 2D roguelike dungeon crawler bullet hell game, inspired by *Enter the Gungeon*. Developed as part of the Orbital 2026 program, the project focuses on robust software engineering principles, modular game architecture, and challenging, replayable gameplay.

## 🎮 Core Features

  * **Roguelike Mechanics:** Randomly generated dungeons ensure a unique experience every run.
  * **Combat System:** Features a shared dynamic weapon system with diverse archetypes, ammo management, and reloading mechanics.
  * **Player Systems:** Tight controls featuring a dash mechanic with invulnerability frames, health management, and persistent upgrades.
  * **Enemy AI:** Includes varied enemy types (melee and ranged) and boss battles with complex attack patterns.
  * **Software Engineering Focus:** Built using clean, modular code architecture, including design patterns like Facade, Singleton, and Observer to ensure maintainability and scalability.
